A personal video studio that runs on one computer

Faceless Studio is a private desktop tool used by a single creator to make short videos and publish them on their own YouTube channels. It is not a public service: there are no accounts, no sign-ups and no other users.

What it does with YouTube

When its owner connects one of their channels, Faceless Studio uses the YouTube Data API to:

  • upload the owner's finished videos to that channel, private first, with a scheduled publish time;
  • read the channel's basic details (its name and id) and the status of the videos it uploaded;
  • read the channel's YouTube Analytics (views, watch time) to see which videos work.

It never deletes or edits existing videos, never posts comments, and never accesses any other channel or Google service.

Where the data stays. Everything runs on the owner's own computer. The permission Google grants is stored in that computer's system keychain; nothing is sent to any server other than Google's own APIs. See the privacy policy.
